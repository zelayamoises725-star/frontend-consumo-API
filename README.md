
# Dragon Ball Explorer

## Descripción

Dragon Ball Explorer es una aplicación web desarrollada como proyecto académico para practicar el consumo de una API pública mediante JavaScript y la función fetch().

Permite consultar personajes del universo Dragon Ball, realizar búsquedas por nombre y visualizar la información recibida en formato JSON.

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Fetch API
- JSON
- API pública de Dragon Ball
- Git y GitHub

## API utilizada

Dragon Ball API:

https://web.dragon-ball-api.com/documentation

Endpoint utilizado:

https://dragonball-api.com/api/characters

## Funcionalidades

- Carga de personajes desde la API.
- Búsqueda de personajes por nombre.
- Presentación de imágenes y datos de los personajes.
- Visualización de la respuesta JSON.
- Copia de los datos JSON al portapapeles.
- Mensajes de estado y manejo de errores.
- Diseño adaptable a diferentes tamaños de pantalla.

## Instalación y ejecución

1. Clonar o descargar el repositorio.
2. Abrir la carpeta del proyecto en Visual Studio Code.
3. Ejecutar index.html mediante una extensión como Live Server.
4. Contar con conexión a Internet para consultar la API.
